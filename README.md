# Roteiro SF

Mini web app/PWA para o roteiro de sábado na Bay Area.

- Salva os checkboxes no iPhone
- Salva a posição da página
- Abre cada deslocamento no Apple Maps
- Funciona offline depois da primeira visita
- Preparado para GitHub Pages

## iPhone

Abra a URL publicada no Safari e use **Compartilhar → Adicionar à Tela de Início**.
